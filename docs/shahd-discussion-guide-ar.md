# دليل شرح جزء Paper Understanding

## الفكرة في جملة واحدة

الجزء يستقبل أجزاء الورقة `DocumentChunk`، ثم يحوّلها إلى كلمات مهمة،
موضوعات، مفاهيم، أقسام مهمة، وأسئلة مقترحة مرتبطة بمصادرها داخل الورقة.

## ترتيب التنفيذ

```text
DocumentChunk
    -> normalize and validate
    -> keyword extraction
    -> topic extraction
    -> concept extraction
    -> important-section ranking
    -> suggested questions
```

نقطة التشغيل الرئيسية هي:

```python
result = PaperUnderstandingAnalyzer().analyze(chunks)
```

## وظيفة كل ملف

- `chunk_adapter.py`: يتأكد أن كل chunk يحتوي على الحقول المطلوبة، ويحوّله
  إلى شكل موحد.
- `keyword_extractor.py`: يستخرج الكلمات والعبارات المهمة باستخدام TF-IDF.
- `topic_extractor.py`: يستخدم أسماء الأقسام والـ keywords لتحديد الموضوعات.
- `concept_extractor.py`: يلتقط الاختصارات والمصطلحات العلمية المتكررة.
- `section_ranker.py`: يرتب الأقسام حسب معنى العنوان وكمية المحتوى.
- `question_generator.py`: ينشئ أسئلة مناسبة لنوع القسم أو المفهوم.
- `analyzer.py`: يشغّل كل الخطوات السابقة بالترتيب ويجمع الناتج.

## شرح TF-IDF ببساطة

`TF` يسأل: هل الكلمة متكررة داخل الـ chunk؟

`IDF` يسأل: هل الكلمة مميزة، أم موجودة تقريبًا في كل chunks؟

نضرب القيمتين معًا حتى تحصل الكلمات المتكررة والمميزة على ترتيب أعلى. بعد ذلك
نحوّل الدرجات إلى نطاق من صفر إلى واحد ليسهل عرضها ومقارنتها.

## كيف نضمن Grounding؟

كل نتيجة تحتفظ بـ `source_chunk_ids`. لذلك نعرف أي أجزاء من الورقة أنتجت
الـ topic أو concept أو question، ويمكن استخدام نفس المعرفات لاحقًا في
الـ retrieval والـ citations.

## لماذا لا نستخدم LLM هنا؟

هذه نسخة MVP محلية ومجانية وحتمية: نفس المدخلات تعطي نفس النتائج، ولا تحتاج
API key أو اتصالًا بالإنترنت. يمكن لاحقًا استبدال extractor واحد بنموذج أقوى
بدون تغيير بقية الـ pipeline.

## أسئلة محتملة في المناقشة

### ما الفرق بين keyword وtopic وconcept؟

- Keyword: كلمة أو عبارة إحصائيًا مهمة.
- Topic: عنوان أوسع يصف جزءًا أساسيًا من محتوى الورقة.
- Concept: مصطلح علمي محدد مثل `Graph Neural Network (GNN)`.

### لماذا نحتفظ بالصفحة والـ chunk ID؟

حتى لا تكون النتائج مجرد تخمينات؛ نستطيع الرجوع إلى النص الأصلي واستخدامه
في الإجابات والمراجع.

### ما حدود النسخة الحالية؟

- موجهة أساسًا للأبحاث المكتوبة بالإنجليزية.
- تعتمد على heuristics وTF-IDF وليست فهمًا دلاليًا عميقًا.
- جودة الموضوعات تعتمد جزئيًا على جودة اكتشاف الأقسام عند معالجة الـ PDF.

### كيف نطورها لاحقًا؟

يمكن تجربة KeyBERT أو sentence-transformers أو نموذج LLM محلي، ثم مقارنة
النتائج باستخدام topic relevance وquestion groundedness وdiversity.
